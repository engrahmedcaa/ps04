LangSmith Updates 🤖 Managed Deep Agents Public Beta : Deploy your Deep Agent to a managed LangSmith runtime with one command, with durable execution, sandboxes, tracing, and more built in. 🔐 LLM Gateway Public Beta : LLM Gateway sits between your agents and the models they call, providing the controls that teams need first when agents go into production: cost controls, rate limits, model fallbacks, and sensitive data handling. 🏎️ LangSmith Engine Performance Improvements : Engine is now more than 2x better at finding agent issues, with proposed fixes that perform 25% better on standard benchmarks. ⚖️ Tuned Evaluators : Automatically attach quality feedback to production traces, so you can find and fix agent mistakes without managing your own judge.
