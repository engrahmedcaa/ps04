The ones that see lasting value will own their intelligence : the model, the harness, and the context that turn a generic model into one that knows your business. At Interrupt NYC and London, we shipped new features to enable teams to own their intelligence, giving them more control over how they build, understand, and improve their agents in production. New in LangSmith 🔎 LangSmith AI Search : Find conversations based on a semantic understanding of your traces, with questions like “did the user get frustrated?” or “did PII leak?” without relying on traditional filters. 🤖 Managed Deep Agents v0.9 : Build dynamic, personalized agents that are tailored to each run's context, react in Slack, have user-level memory and tool use, schedule tasks, and more. Plus, built-in web search for free. 🛡️ LangSmith Engine v2 : Catch issues before they reach production with Red Teaming. Engine v2 also detects harder-to-spot issues like inefficient agent work and metric trends, and automatically tests and validates its proposed fixes. 🧭 LangSmith Trajectories : Navigate trace data and follow your agent’s path with a chronological view of each session across the main agent and its subagents. 🧩 LangSmith Custom Apps : Build, publish, and run custom interfaces directly in LangSmith, turning recurring workflows into shared tools built on your LangSmith data. 🎛️ LangSmith Fine-Tuning : Turn production trajectories into training data, fine-tune models with Baseten or Fireworks, then evaluate and serve the tuned models. Open source 🔧 LangChain v1.4.0 : LangChain now supports FastMCP through the langchain.mcp namespace. ⚡ Building production agents with Jev and LangGraph : See how LangGraph orchestrates Jev, TypeSafe AI’s decision model, to build agents that are faster and cheaper to run. The Agentic Operating Model: How teams are running production AI at scale The Agentic Operating Model looks at how leading teams bring people, processes, and technology together to scale production AI. It covers rethinking the agent development lifecycle, building continuous evaluation practices, and embedding governance: what it takes to move beyond experimentation and run agents reliably at scale.
