# Video script instructions

Write a 3–5 minute audience-facing script (roughly 450–700 spoken words) for AI application developers at small teams. Use the same reviewed brief and evidence as the companion article, while adapting explanations for listening. Include narration, useful visual directions, claim markers, exact source links, and timestamps for media evidence. Explain practical developer implications and uncertainties. Keep factual claims consistent with the article, do not overstate vendor benchmarks or production readiness, and disclose AI-generated presentation where used.
